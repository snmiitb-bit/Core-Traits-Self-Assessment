# Core-Traits-Self-Assessment
A web application built with Streamlit that allows candidates/students to complete a bilingual (English &amp; Tamil) Big Five personality traits self-assessment based on an Excel template, review their ratings, and instantly download a professionally formatted PDF certificate.
Features
Bilingual Interface: Displays traits and facets in both English and Tamil for clear understanding.

Interactive Evaluation: Interactive sliders (1 to 5 scale) and optional comment/example fields for each personality facet.

Automated PDF Certificate Generation: Uses ReportLab to generate a clean, official certificate complete with organization branding, candidate details, rating tables, and signature blocks.

Direct Download: Provides a one-click Streamlit download button for the generated PDF.
